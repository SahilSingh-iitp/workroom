# WORKROOM — AI tools and prompts log

## Tools
- ChatGPT (GPT-6): problem framing, product scope, challenge design, copywriting, implementation and code review.
- HTML, CSS and vanilla JavaScript: static responsive frontend.
- Google Sheets + Google Apps Script: submission collection backend (requires owner setup).
- Vercel or Netlify: static hosting (requires owner account and deployment).

## Prompt 1 — Product framing
"Design the smallest useful MVP for college students across all disciplines who lack access to practical exposure. It should support individual and team challenges, avoid job matching/resume scoring/career roadmaps, and produce evidence of practical work."

## Prompt 2 — Challenge design
"Create short, accessible real-world challenges for students from any academic discipline. Accept non-code deliverables such as research, process redesigns, prototypes, explainers and test plans. Each challenge must include a clear task, user validation and evidence-based deliverables."

## Prompt 3 — Frontend implementation
"Build a responsive, accessible, mobile-first static website with a challenge board, solo/team filters, detailed challenge briefs, and a structured submission form. Use plain HTML, CSS and JavaScript; no login and no fabricated testimonials or metrics."

## Prompt 4 — Submission collection
"Create a Google Apps Script doPost endpoint that accepts JSON submissions and appends them to a Google Sheet with a header row. Include explicit setup instructions and make clear that the endpoint must be deployed by the owner."

## Prompt 5 — Quality and honesty review
"Review the MVP for broken interactions, unclear instructions, accessibility, mobile layout, data privacy and misleading claims. Ensure preview-mode submissions are clearly disclosed and no user research or usage metrics are fabricated."

## Disclosure
The site copy, challenge structure and code were AI-assisted. The founder must personally conduct interviews, invite testers, observe usage, record consent, verify submissions and report real metrics. No student quotes, testimonials, user counts or completion results are invented in this project.
